# Referenskortet (The Referral Card)

BNI referral postcard designer — single-page app, print-ready PDF export.

## Live

https://referenskortet.pages.dev/

## Local
Open `index.html` in a browser. No build step.

## Deploy

Cloudflare Pages project: `referenskortet`. Static upload of `index.html` (or connect this repo to Pages).

## Codex / collaborators

This repo is the shared source of truth. Keep the app as a single `index.html` unless we deliberately split assets. Do not commit Cloudflare API tokens.
